# Injury Engine rename handoff (SkyrimNet_Leashed)

SkyrimNet_Whipped is being renamed **Injury_Engine** before its first release. This repo uses it as a soft dependency (fall and leash-drag injuries, sent through a VM dispatch), so it must follow the rename. The full spec covering all three repos is `../SkyrimNet_Whipped/injury-engine-handoff.md`. This file lists only what changes here.

- New names on the Injury Engine side: plugin `Injury_Engine.esp`, main script `Injury_Engine_Main`, dashboard config `Injury_Engine`, injuries folder `SKSE/Plugins/Injury_Engine/injuries/`.
- The mod has never shipped, so keep no fallback to the old names.
- Deploy this repo together with the renamed Injury Engine. An old Leashed DLL looks up `SkyrimNet_Whipped.esp` and will treat Injury Engine as missing.
- Do not commit unless asked. Do not edit this file during a search-replace.

## Substitution rules

Apply in this order, case-sensitive. Do **not** blind-replace the substring `whip`.

| From | To |
|------|-----|
| `SkyrimNet_Whipped` | `Injury_Engine` |
| `skyrimnet_whipped` | `injury_engine` |
| `SkyrimNet Whipped` | `Injury Engine` |
| `leash.whipped.` | `leash.injuryengine.` |
| code identifier `Whipped` (meaning that mod) | `InjuryEngine` |
| prose "Whipped" (meaning that mod) | "Injury Engine" |

## File move

```text
git mv SKSE/Plugins/SkyrimNet_Whipped/injuries/leash_dragging.json SKSE/Plugins/Injury_Engine/injuries/leash_dragging.json
```

Remove the empty `SKSE/Plugins/SkyrimNet_Whipped/` afterwards.

## Leave unchanged

- Injury source ids `falling` and `leash_dragging`.
- The dispatched Papyrus global `External_Damage`.
- `whip` / `whipping` wherever it means the whip itself.

## Build

The DLL build globs `src/*.cpp`, so the moved files need a fresh configure. There is no `make dll` target here.

```text
cd SKSE_Source
cmake --preset release            # fresh configure (or delete build/ first)
cmake --build --preset build-release
# copy the built SkyrimNet_Leashed.dll into SKSE/Plugins/
cd ..
pyro skyrimse.ppj                 # required: native names changed
```

## Done when

Grep the repo (excluding `.git`, `SKSE_Source/build/`, `z-*` and this file). Expect **no hits** for:

```text
SkyrimNet_Whipped|skyrimnet_whipped|SkyrimNet Whipped|leash\.whipped|WhippedInjure|WhippedFallDamage|toWhipped|Whipped::|src/Whipped
```

- `SKSE/Plugins/Injury_Engine/injuries/leash_dragging.json` exists.
- The DLL is rebuilt and `.pex` files are recompiled.
- In game, with "Falling hurts" on and Injury Engine installed, a yank that knocks someone down applies `falling`, and dragging applies `leash_dragging` through `Injury_Engine_Main.External_Damage`. `SkyrimNet_Leashed` logs `InjuryEngine: installed=true`.
