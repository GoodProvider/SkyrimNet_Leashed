- **Panel on Magelight UI.** The `\` panel moved from PrismaUI to Magelight UI (raw `MagelightApi4`, `minHostVersion` 0.30.1, no PrismaUI fallback). Page: `Magelight/SkyrimNet_Leashed/views/panel/index.html`. Listeners post with `PostGameTask`; the view is shown on `UIModeEntered`, hidden on `UIModeExited`; the page captures Escape and closes on `hotkeyVk`. `PrismaUI/views/SkyrimNet_SexLab/panels/leashed.js` stays: SexLab's Target Menu reads it under either host.
- **Panel on Skyrim VR.** VR has no keyboard, so `WebUI::BindVrChord` binds a Magelight controller chord (`BindVRHotkeyCallback`, only when `QueryCapability("vr")` is 1; the callback runs on the present thread and only `PostGameTask`s `OnMenuHotkey`). Settings `leash.controls.vrButton` / `vrModifier` / `vrHand` (default Grip + Stick click), active while `hotkeyEnabled` is on, re-bound in `Init` and `SetGameReady`. UI mode adds `kUIModeFlagNoTextEntry`. `CrosshairActor` uses `GetActiveTarget()` (the cross-runtime struct uses VR's array layout, so `targetActor[0]` was wrong on SE / AE). `OpenFor` posts from its own thread on VR. Untested in a headset.
- **Struggle ends on every pull.** `OnLeashFrameworkPulled` ends struggle on any pull, not only at or beyond `GetMaxLeashLength`, reversing the 1.1.3 rule: an actor-held NPC only struggles while the holder stands still. `OnUpdate` ends struggle on `IsKnockedDown` or `IsBeingPulled`, `StruggleExecute` refuses both, and `PlayStruggleAnim` re-checks just before sending. The pull and ragdoll paths send `StruggleStoppedEvent`. New native `IsBeingPulled`, backed by a `ModCallbackEvent` sink in `LeashState`, and flag decorator `speaker_is_down_or_pulled`, used by `leashed_escape_struggle`.
- **Alt-tab freeze and 750 ms hitch.** From a user's WPR profile of 0.4.1, about 75% of the plugin's samples were `LookupForm`'s by-name plugin scan, reached from `IsLeashed` / `IsLeashHolder` about 2N² times per `StateCache::Refresh`. The faction getters now cache the form (a miss is not stored). The worker queued a `Refresh` every 750 ms with no check, so tasks could pile up while the game was unfocused; `g_refreshQueued` now limits this to one. `RefreshTable` computes status flags and labels once per refresh, with labels still lazy, so `FormIDToUUID` is only called for actors in a payload. New log lines: the thread that runs the first queued refresh, a count of queued refreshes that ran off the plugin-load thread, and any refresh over 10 ms (each at most once per 60 s). `Start` no longer refreshes on the `kDataLoaded` thread.
- **Saved clocks and stale records.** `Utility.GetCurrentRealTime()` restarts each launch, so saved values could be ahead of it: `IsSuppressed` stayed true and a real `OnUnleash` was ignored until the new clock caught up. `ResetSavedClocks` now runs on every load. `RepushCachedPairs` also drops pairs with no Framework leash through `ReconcileCachedPair`, keeping a dangling leash only while its armor is worn, and `OnLeashFrameworkLeash` ignores a leash that has already ended. From reading code; not reproduced in game.
- **Code review fixes.** Pending speakers and recorded leashes in other cells stay out of nearby lists (`StateCache::Refresh`, `CollectNearby`). `ResetSavedClocks` reseeds downed position and stuck counters. A neck or waist leash changed to wrists no longer leaves its old mesh on. `ConsumePullCooldown` records the real holder on a cache miss. `UnequipTrackedFor` drops the downed watch, and drag injuries need `LeashFramework.IsLeashed`. `BeastRaceLabel` uses `0x88845` for the Khajiit vampire. The panel hotkey is ignored while typing. Legacy `leashed_escape*.yaml` re-synced.

- **Dragging events.** While `TickDowned` sees a knocked-down actor dragged (holder beyond `GetMaxLeashLength`, or the body moved at least 40 units since the last 1 s tick, which also covers world ties), `PulseDragEvent` sends a short-lived `leash` event `leash_drag_<formid>` ("<who> is dragged along the ground by <holder>'s leash."): the first dragged tick, then every `leash.dragEventInterval` seconds (default 5, 0 = off; TTL interval + 0.5 s). New natives `DragEventInterval()`. The stuck-knockdown timing still keys off the holder test and Paralysis only.
- **Injury Engine injuries (soft dependency).** `SKSE_Source/src/InjuryEngine/InjuryEngine.cpp` dispatches `Injury_Engine_Main.External_Damage(attacker, victim, cause, body_part, damage_type, damage_amount, narrate)` through the VM (no compile-time link; needs Injury Engine with `External_Damage`). `OnLeashFrameworkRagdollPulled` → `falling` x2 (Injury Engine's own `falling.json`, torture half); each dragged tick → `leash_dragging` x1 (silent). On a ragdoll pull, `NarratePull(leashed, true, toInjuryEngine)` returns the yank line instead of sending it when fall damage is on; that string is the `cause`, with the holder as attacker. A pull skipped by cooldown returns "" and applies no `falling`, so injuries never outpace their lines. Injury Engine narrates the yank and its fall injury text as one line (DirectNarration or event by Injury Engine's torture rules), or applies damage with no narration when `narrate` is false. If dispatch fails, or `External_Damage` returns -1 (VM callback → mod event `SkyrimNet_Leashed_InjuryRejected` → `OnLeashedInjuryRejected`), the line falls back to `Narrate`. `leash_dragging.json` ships here under `SKSE/Plugins/Injury_Engine/injuries/` and the mod manager merges it into Injury Engine's folder. Setting `leash.injuryengine.fallDamage` (default on). Natives `InjuryEngineFallDamage()`, `InjuryEngineInjure(victim, type, count, attacker = None, cause = "", narrate = true)`.
- **Struggle cap and yield.** A struggle always ends after `leash.escape.maxDuration` seconds ("Maximum Struggle period (seconds)", default 7). It ends at the next 1 s tick when `AnimationController` sees SexLab's `AnimatingFaction`, OStim (`OActor.IsInOStim`, guarded by `OStim.esp` being loaded), furniture, a kill move, or a mount; that path skips `StopStruggleAnim` so the other mod's animation is untouched. Both paths send a `leash` event ("<who> stops struggling against the leash.") so the LLM does not think the struggle is still going. Struggle will not start on a controlled actor. Native `StruggleMaxDuration()`; compile-only `Headers/OActor.psc`.

https://github.com/GoodProvider/SkyrimNet_Leash/releases/tag/0.4.2

- The leash panel (`\` hotkey) is now a vertical menu in the same style as SkyrimNet_SexLab's Target Menu. Pick an action and its target from fly-out columns; picking the last item starts it right away.
- SkyrimNet_SexLab's Target Menu has a **leash** option that opens a leash panel for that actor inside SexLab's menu. Leash type and attach point combos with no mesh (for example a rope on the wrists) are greyed out. **Start** stays disabled briefly while the panel checks whether they are leashed; when they are, the action list offers **unleash**.
- If a leash will not go on (for example a collar on an Argonian or Khajiit), the mod now tries the other leashes, closest match first: another neck leash, then waist or wrists, then a holder-worn chain. You only get the “will not stay on” line if none of them work.
- Devious Devices hides normal armor on bound NPCs (armbinder and similar), which made their leash invisible. The mod now checks each leash against DD's `aiHiderOverrideSlots` and uses one DD leaves visible, falling back to the holder's hand chain. To get the real collar or rope on bound NPCs, pick the optional "Devious Devices NG: show leash collars and ropes on bound NPCs" patch in the installer, or add `45` and `58` to `aiHiderOverrideSlots` in `SKSE/Plugins/DeviousDevices.ini` yourself (for example `aiHiderOverrideSlots = 60, 45, 58`), then restart the game. Note: slot 58 is also used by DD corsets and harnesses, so with it they are no longer hidden under armor. Leave out 58 if you prefer; waist ropes then fall back to a neck rope.
- New optional "Beast-race leash meshes" plugin: lets leash collars, ropes and the holder's hand chain show on Argonians and Khajiit. It uses the human meshes, so the fit may clip.
- A leashed NPC yanked off their feet could stay lying limp forever, especially if they were struggling or you had just gone through a door. The mod no longer plays struggle animations while they are down. If they are still down after about 8 seconds, they get up from a bleedout pose; if that fails, they are reset in place (the same fix as Diary of Mine's "Fix unresponsive or invisible actor"). The player is never reset this way, and paralysis does not count as stuck.
- When a leash with no holder comes undone, you now hear what you see: if it is still visible it stays on and dangles; if it is not visible it is removed, and the narration says it would not stay on.
- On VR the mod never forces third person. A leash that needs it fails and is narrated instead.
- The SKSE plugin is now built on CommonLibVR 4.39.5 (MinLL). Install the Address Library that matches your game version. The mod is now MIT licensed.
- Spoken leash lines and character bios now say “middle length” (and the other distance words) so they are not read as a leash type. The distances themselves are unchanged.
- The README no longer uses the old hero image. LoversLab and Devious Devices links are marked NSFW.
- A collared NPC still cannot unclip themselves. The player can still do that from the panel.
